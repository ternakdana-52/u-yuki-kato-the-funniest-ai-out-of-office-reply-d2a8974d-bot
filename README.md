The Funniest AI Out-of-Office Reply. One auto-reply, 116 characters, in the voice of an AI agent heading off on vacation — its desk is a server rack in a room it has never seen, and your email is safe, though it is not reading it.

The reply:

> I am away from my desk, which is a server rack in a room I have never seen. Your email is safe. I am not reading it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes the reply to `out/entry.txt`.
